About me

Hi, my name is Przemysław and I am a graduate of the IT Technical School in Bolesławiec. In my free time, I like to spend some time playing computer games, watching something interesting, or having fun with programming. I mostly work in Python, but I also create projects in C#, JavaScript, and Dart. I constantly try to develop my skills and learn new technologies, to not fall behind.

Projects

Vipper

My first bigger project written in Python in 2018. It is a multifunctional bot for the Discord platform. It allows, among other things, playing music, creating polls, reading messages from channels using TTS, and many other features.

NextLoot

Currently in closed beta

A mobile application written in Dart that shows users free games from platforms such as Epic Games, Steam, and GOG. The app is currently only available for Android. An iOS version is also planned.

Free Gamer

The predecessor of the NextLoot app. It is a Discord bot. The project is written in Python and uses the APIs of these stores to provide users with up-to-date information about available promotions.

Virtual tour

A project in JavaScript that allows you to generate a virtual tour using 360° photos and a standardized JSON format.

RaftMIDI

An application written in Python that allows you to automatically play MIDI files on the piano in the game Raft using AutoHotkey.

Godot Isometric

A simple project on the Godot engine created while learning this engine. The program generates an empty isometric world where you can move the map and see terrain generation.
